Кто есть кто в движении, кто что предлагает и ищет, с кем по каким темам возможно взаимодействие — по заявлениям самих организаций, с источниками.

Карта вокруг организации

Выберите организацию — она окажется в центре. Остальные расположены по радиусу: ближе — выше гипотетический потенциал взаимодействия, дальше — ниже. Клик по точке — из чего складывается потенциал.

Карта строится по гипотетическому потенциалу — какие форматы взаимодействия возможны для пары, судя по их ролям (образование, медиа, профсоюзы, библиотека…; для черновиков сферы выведены из раздела списка), усиленному заявленным в паспортах: возможные форматы по ролям (+2 за формат, до 6), общие сферы (+1, до 4), заявленная взаимодополняемость «предлагаю × ищу» (+2, до 6), общие темы с утверждёнными обеими сторонами позициями (+1, до 3), подтверждённая связь (+2), оба паспорта утверждены (+1); нормировка к 10. Заявленные политические ограничения учитываются как потолок (статусы карты ThinkRed: «расхождения по методу» ограничивают потенциал точечными кампаниями, «не взаимодействуем» — почти обнуляют). Радиус нормируется к самой близкой организации текущего выбора — кольца подписаны фактическими значениями потенциала. Это гипотеза для первого разговора, а не факт сотрудничества и не оценка политической совместимости: реальную совместимость устанавливают только сами организации.

Как участвовать: проверьте карточку своей организации и утвердите паспорт — 30 минут по инструкции в репозитории. Формат данных и код — свободные (MIT): github.com/thethinkred-ai/interop-map · зеркало на thinkred.ru/interop. Методология: как устроены карточки и оценки.
