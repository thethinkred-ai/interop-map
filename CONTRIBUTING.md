# Участие

## Утвердить паспорт своей организации

Кратко: найдите себя в `data/orgs/` → заполните по [handbook/PASSPORT.md](handbook/PASSPORT.md) → `python scripts/validate.py ORG-XXX` → pull request → подтвердите публичным каналом. Детали — в паспорте-руководстве.

## Исправить черновик (не своя организация)

Только факты и только с источниками: исправляете текст, источник добавляете в `meta.source` или в соответствующее поле. Оценки и ярлыки не принимаются.

## Добавить связь

Строка в `data/connections.json` по схеме `schema/connection.schema.json`. Обязателен URL-доказательство. «Вместе выступили на одном форуме» — не связь; «вместе издают журнал» — связь.

## Добавить карточку исследования

Файл `data/cards/<org-id>.jsonl` (одна строка JSON = одна карточка) по схеме `schema/research-card.schema.json`. Атрибуция (`researcher`) обязательна. Валидатор проверит: баллы 0–4 или null, даты ГГГГ-ММ-ДД, приоритет А/Б — только с фактами, резюме при заполненном статусе.

## Технические PR

Скрипты и витрина — обычный код: чистые правки, без новых зависимостей (Python 3.8+, stdlib only). Перед PR на витрину запускайте `python scripts/build_site.py` и прикладывайте скриншот, если меняли UI.

## чего мы не примем

- политических оценок в данных (только позиции организаций с источниками и атрибутированные карточки);
- паспортов «за другую организацию» со статусом `asserted`;
- персональных данных частных лиц;
- данных без источников.
