# Карта взаимодействия — открытый сервис для организаций движения

**Кто есть кто. Кто что предлагает и ищет. С кем и по каким темам возможно взаимодействие.**

Открытый формат данных и витрина, в которой 200–400 организаций движения могут за минуты определить, как взаимодействовать друг с другом: попарные матч-отчёты, паспорт организации, подтверждённые связи. Методология — [ThinkRed](https://thinkred.ru); формат, код и данные — свободные (MIT).

## Три принципа, на которых всё держится

1. **Без рейтингов и ярлыков.** Система не вычисляет «степень ортодоксальности» и не ранжирует организации. Есть только попарные отчёты и атрибутированные карточки исследователей.
2. **Паспорт — голос самой организации.** Позиции принимаются исключительно с источниками (URL + цитата). Черновики, составленные по открытым данным, всегда помечены `asserted: false` и не являются заявлением организации.
3. **«Не установлено» — штатное состояние.** Молчание паспорта не означает ни согласия, ни отказа. Факты отделены от оценок; оценки всегда атрибутированы.

## Что здесь лежит

```
taxonomy.json            справочники: темы позиций, типы деятельности, форматы взаимодействия
schema/                  JSON-схемы: паспорт (orgpass), карточка исследования, связь
data/orgs/               паспорта организаций: ORG-000 (ThinkRed) + ORG-001…ORG-209 (посев-черновики)
data/connections.json    подтверждённые связи между организациями
data/source/             снимок источника посева (thinkred.ru/cooperation, 17.10.2026)
scripts/validate.py      валидатор всех данных
scripts/match.py         матч-отчёт двух организаций (CLI)
scripts/seed_from_coop.py конвертер снимка → черновики паспортов
scripts/build_site.py    генератор витрины → docs/index.html
handbook/                PASSPORT.md · METHODOLOGY.md · GOVERNANCE.md
docs/                    статическая витрина (GitHub Pages)
```

## Быстрый старт

```bash
git clone https://github.com/thethinkred-ai/interop-map.git
cd interop-map
python scripts/validate.py                 # проверить все данные
python scripts/match.py ORG-000 ORG-029    # матч-отчёт ThinkRed ↔ REDSTARTER
python scripts/match.py ORG-000 ORG-029 --json
python scripts/build_site.py               # пересобрать витрину
```

Зависимостей нет — только Python 3.8+.

## Как утвердить паспорт своей организации (30 минут)

1. Найдите себя в `data/orgs/` (или создайте `ORG-XXX.json` по схеме `schema/orgpass.schema.json`).
2. Заполните: идентификацию, каналы, **позиции с источниками** (по таксономии из `taxonomy.json`), деятельность, блок `cooperation` (предлагаете / ищете / условия).
3. Проверьте: `python scripts/validate.py ORG-XXX`.
4. Откройте pull request. Подтверждение — любой публичный канал организации (пост, письмо с адреса домена, сообщение в официальном TG/VK). После проверки мы выставим `asserted: true`.
5. Готово: ваша организация появляется в матч-отчётах всех участников с вашими формулировками.

Подробно: [handbook/PASSPORT.md](handbook/PASSPORT.md). Правила и безопасность: [handbook/GOVERNANCE.md](handbook/GOVERNANCE.md). Как читать карточки: [handbook/METHODOLOGY.md](handbook/METHODOLOGY.md).

## Что показывает матч-отчёт

- **Взаимодополняемость** — пересечение «предлагаю × ищу» обеих сторон;
- **Общие темы** — только те, где позиции утвердили обе организации (иначе — «открыто»);
- **Рекомендованные форматы** первого проекта из справочника (обмен публикациями, рецензирование, совместный семинар, обмен мониторингом трудовых конфликтов…);
- **Черновик первого обращения** — заготовка письма, которую правите под себя.

Отчёт — сопоставление заявленного, а не приговор о совместимости. Расхождения показываются, а не оцениваются.

## Данные-посев и честность

Стартовый реестр — 209 черновиков, собранных по открытым данным из [карты взаимодействия ThinkRed](https://thinkred.ru/cooperation/) (снимок 17.10.2026). Все они помечены `asserted: false`. Задача посева — чтобы каждой организации было **что проверять и дополнять**, а не начинать с пустого листа. Любая организация может: исправить черновик, утвердить паспорт, ограничить видимость или удалиться из реестра — [см. GOVERNANCE](handbook/GOVERNANCE.md).

## Участие

Pull request'ы приветствуются: исправление фактов в черновиках (с источниками), новые связи (с доказательствами), улучшение скриптов и витрины. Политические оценки в данных не принимаются — только позиции организаций с источниками и атрибутированные карточки исследователей.
