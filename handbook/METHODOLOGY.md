# Методология: как читать данные карты

Короткий документ для организаций-участниц и исследователей. Полная методика исследования организаций (паспорт, карточка, реестр, категории, банк проектов) разработана ThinkRed и используется этим сервисом.

## Три рода записей — три разных голоса

| Запись | Чей голос | Что удостоверяет |
|---|---|---|
| **Паспорт** (`data/orgs/`) | сама организация | «мы заявляем это о себе», с источниками |
| **Карточка исследования** (`data/cards/`) | исследователь (организация-участница или независимый), всегда с атрибуцией | «мы установили это по таким-то источникам» |
| **Связь** (`data/connections.json`) | любой участник с доказательством | «между этими организациями есть подтверждённая связь» |

Смешение этих голосов — главная ошибка, которую система исключает конструктивно: у каждого файла свой формат и своя подпись.

## Статусы фактов

В карточках исследования каждый факт имеет один из четырёх статусов:

- **confirmed** — подтверждено первоисточником (программа, устав, официальное заявление);
- **refuted** — опровергнуто;
- **not_established** — не установлено. **Не найденное не значит несуществующее**: не найденная программа не доказывает её отсутствия;
- **not_applicable** — неприменимо.

## Позиции: молчание не интерпретируется

В матч-отчётах общая тема появляется **только если обе стороны утвердили позицию** по ней. Если утвердила одна — тема попадает в «открытые вопросы» (уточнить), если ни одна — не попадает никуда. Отсутствие заявления не доказывает ни согласия, ни несогласия.

## Оценки: атрибутированные, не суммарные

Карточка исследователя может содержать пять оценок 0–4 (идейная и практическая совместимость, взаимная полезность, подтверждённая активность, доступность контакта). Правила:

- оценка принадлежит **исследователю**, а не системе и не исследуемой организации;
- «Н/Д» (null) при нехватке данных — не ноль;
- система **не суммирует** оценки в балл организации и не строит рейтингов: принципиальное противоречие не компенсируется высокой активностью, а низкая доступность контакта не означает идейной несовместимости;
- у одной организации может быть несколько карточек от разных исследователей — противоречия между ними показываются, а не усредняются.

## Категории приоритета А–Д

Категория в `meta.page_category` — это приоритет взаимодействия из карты ThinkRed (посев данных), оценка ThinkRed, а не свойство организации:

- **А** — первоочередной контакт; **Б** — перспективный; **В** — точечные кампании; **Г** — наблюдение; **Д** — не взаимодействуем.

Категория «Д» — не приговор навсегда и не политическая оценка организации; пересматривается при изменении практики. После утверждения паспортов организациями категории из посева остаются в `meta` как исторические данные ThinkRed.

## Связи: что считается доказанной связью

Совместный проект, коалиция, обмен публикациями, совместное мероприятие, международная сеть — с URL-доказательством. **Не связь**: одинаковая идеология, взаимные подписки, совместное участие в чужом мероприятии. Конфликты (`split`, `public_conflict`) фиксируются наравне с сотрудничеством — с качеством свидетельств.

## Матч-отчёт — не вердикт

Отчёт сопоставляет заявленное: пересечение «предлагаю × ищу», общие утверждённые темы, общие типы деятельности. Вывод «совместимы/несовместимы» он не делает — это решение остаётся организациям. Расхождение позиций — предмет разговора, не основание для исключения из карты.

## Два слоя оценки: заявленное и гипотетическое

Сервис различает два слоя, и подписывает их везде явно:

1. **Заявленное (факт):** что организации реально написали в паспортах — предложения, запросы, позиции с источниками. Матч-отчёт всегда показывает этот слой отдельно.
2. **Гипотетический потенциал (карта):** какие форматы взаимодействия *возможны* для пары, судя по их ролям — сферах деятельности (образование, медиа, профсоюзы, библиотеки…). Для черновиков сферы выводятся из раздела списка-посева и помечаются. Слагаемые: возможные форматы по ролям (+1 за формат, до 5), общие сферы (+0.5, до 1.5), заявленная взаимодополняемость (+2 за совпадение, до 6), общие темы с утверждёнными обеими сторонами позициями (+0.5, до 2.5), подтверждённая кооперативная связь (+2), оба паспорта утверждены (+0.5); нормировка к 10. Заявленные политические ограничения применяются как потолок: «расхождения по методу» (статус карты ThinkRed) ограничивает потенциал точечными кампаниями, «не взаимодействуем» — почти обнуляет.

Потенциал — **гипотеза для первого разговора**: он не утверждает, что сотрудничество желательно, политически возможно или что организации согласны друг с другом. Пустой по ролям результат означает «не найдено общих форматов по имеющимся данным», а не «несовместимы». Реальную совместимость устанавливают только сами организации.
