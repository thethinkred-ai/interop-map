# Как заполнить паспорт организации

Паспорт (`schema/orgpass.schema.json`) — это голос вашей организации. Заполняется за ~30 минут. Ниже — по полям, с примерами.

## Минимум для утверждения (обязательные)

```json
{
  "schema_version": "1.0",
  "id": "ORG-XXX",
  "asserted": false,
  "identity": {
    "name": "Название организации",
    "country": "Россия",
    "languages": ["русский"],
    "legal_form": "незарегистрированная инициативная группа",
    "status": "действует"
  },
  "channels": { "site": "https://…", "telegram": "https://t.me/…" }
}
```

## Позиции — только с источниками

Каждая позиция: тема из таксономии (15 тем в `taxonomy.json`), формулировка до 800 знаков, статус и **источник** (URL + цитата + дата).

```json
{
  "topic": "nature_of_state",
  "stance": "Государство — орган классового господства буржуазии; слом государственной машины — условие перехода к социализму.",
  "status": "asserted",
  "sources": [
    { "url": "https://example.org/programma", "quote": "…прямая цитата из вашего документа…", "date": "2024-05-01" }
  ]
}
```

Статусы позиции:
- `asserted` — утверждено вашей организацией (обязателен источник);
- `discussed` — позиция обсуждается, публикация есть, но не утверждена;
- `open` — вопрос открыт.

**Отсутствие темы = «не заявлено».** Это не согласие и не несогласие — так и работает система. Не заполняйте темы «наугад»: пустое поле честнее приблизительного.

## Деятельность

Тип из таксономии + описание + доказательства (ссылки):

```json
{ "type": "education", "description": "Кружки по «Капиталу», еженедельно", "proofs": ["https://t.me/…"] }
```

## Блок cooperation — сердце матчинга

```json
"cooperation": {
  "offers": [
    { "format": "exchange_publications", "description": "Размещаем статьи партнёров в нашем журнале" }
  ],
  "seeks": [
    { "format": "labour_monitoring_exchange", "description": "Источники о трудовых конфликтах в регионах" }
  ],
  "conditions": ["Идейная самостоятельность сторон"],
  "red_lines": ["Не подписываем совместные заявления с непроверенными цитатами"]
}
```

Форматы — из `taxonomy.json` (`interaction_formats`). Именно пересечение `offers` одной организации с `seeks` другой даёт в матч-отчёте «взаимодополняемость».

## Видимость и безопасность

```json
"visibility": { "level": "public", "contacts_public": true }
```

- `public` — паспорт виден целиком;
- `restricted` — в реестре остаётся только строка «существует»;
- `contacts_public: false` — паспорт виден, контакты скрыты.

Удаление из реестра — по первому запросу организации (см. [GOVERNANCE.md](GOVERNANCE.md)).

## Проверка и отправка

```bash
python scripts/validate.py ORG-XXX   # ошибки покажет валидатор
```

Затем — pull request. `asserted: true` выставляется после подтверждения через ваш публичный канал (пост в официальном TG/VK, письмо с адреса домена организации). До этого паспорт честно помечен как черновок.

## Что нельзя

- Позиции без источника со статусом `asserted`;
- оценки третьих организаций внутри вашего паспорта (для этого — карточки исследователя);
- чужие материалы как свои доказательства;
- персональные данные частных лиц (только публичные роли публичных лиц).
