# Правила и безопасность

## Кто что может

| Действие | Кто | Как |
|---|---|---|
| Исправить черновик своей организации | организация (или любой — с источниками) | PR |
| Утвердить паспорт (`asserted: true`) | организация | PR + подтверждение публичным каналом |
| Ограничить видимость (`restricted`) | организация | PR или запрос |
| **Удалиться из реестра** | организация | запрос — выполняется без условий |
| Добавить карточку исследования | любая организация/исследователь | PR, атрибуция обязательна |
| Добавить связь | любой | PR с URL-доказательством |
| Менять схемы/таксономию | мейнтейнеры (сейчас ThinkRed) | версионно, с обратной совместимостью |

## Подтверждение утверждения паспорта

Чтобы паспорт получил `asserted: true`, организация подтверждает его одним из способов:

1. пост в официальном канале организации (TG/VK) со ссылкой на PR;
2. письмо с адреса домена организации;
3. сообщение с официального аккаунта, указанного в уже утверждённом паспорте.

Мейнтейнеры (сейчас — ThinkRed) проверяют и выставляют флаг. В спорных случаях паспорт остаётся черновиком.

## Безопасность участников

1. **Только публичные данные.** Паспорта собираются из открытых источников; контакты публикуются с явного согласия (`contacts_public`).
2. **Право на тень.** Организация может быть в реестре строкой «существует, паспорт закрыт» (`restricted`) — или отсутствовать.
3. **Удаление без условий.** Запрос организации на удаление выполняется; публичная история при этом не сохраняется.
4. **Без персональных данных.** Только организации и публичные лица в их публичных ролях.
5. **Честная маркировка.** Черновики визуально и машинно отличимы от утверждённых паспортов везде — в данных, на витрине, в матч-отчётах.

## Чего система не делает никогда

- не вычисляет «степень ортодоксальности» и подобные метрики;
- не публикует глобальных рейтингов и «списков врагов»;
- не принимает анонимных оценок — любая оценка атрибуирована;
- не использует число подписчиков как показатель силы организации;
- не трактует молчание как позицию.

## Конфликты вокруг данных

- **Спор о факте:** показываются обе стороны с источниками; мейнтейнеры не выбирают «правильную».
- **Спор об оценке:** оценки не удаляются по требованию оцениваемого — они атрибутированы и есть мнение исследователя; но фактические ошибки в них исправляются.
- **Спор о связи:** без URL-доказательства связь не существует.

## Роль ThinkRed

ThinkRed — автор методологии и текущий мейнтейнер инфраструктуры. Это не даёт ThinkRed права на вердикты об организациях: собственные оценки ThinkRed живут в его карточках исследователя на общих основаниях. Цель — передать мейнтейнансе коллегиальной группе организаций-участниц по мере роста.

## Лицензия и форки

Всё — MIT. Любая организация может форкнуть формат и данные; машинная совместимость поддерживается версионированием схем (`schema_version`).
